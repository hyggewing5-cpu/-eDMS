# eDMS — ระบบจัดเก็บเอกสารออนไลน์

หน้าเว็บอยู่บน **GitHub Pages** · ฐานข้อมูลและไฟล์อยู่ใน **Google Sheets + Google Drive** · Apps Script ทำหน้าที่เป็น API

```
เบราว์เซอร์ ──► GitHub Pages (index.html + config.js)
                    │  POST (JSON)
                    ▼
              Apps Script Web App (Code.gs)  ──► Google Sheets (ข้อมูล) + Drive (ไฟล์)
```

## ไฟล์ใน repo
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บทั้งหมด (ไทย/อังกฤษ) |
| `config.js` | ใส่ URL ของ Apps Script (แก้ไฟล์นี้ไฟล์เดียว) |
| `Code.gs` | โค้ด backend นำไปวางใน Apps Script |

## ติดตั้ง

### ส่วนที่ 1 — Apps Script (backend)
1. สร้าง Google Sheet ใหม่ เช่น `eDMS_DB` แล้วเปิด **ส่วนขยาย → Apps Script**
2. วางเนื้อหา `Code.gs` ทับของเดิมทั้งหมด (ใช้ไฟล์เดียว ไม่ต้องมี `Index.html`)
3. เลือกฟังก์ชัน **`setup`** → **เรียกใช้** (อนุมัติสิทธิ์ Sheets/Drive ครั้งแรก)
4. **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → เว็บแอป**
   - ดำเนินการในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน** (ต้องเป็น "ทุกคน" ไม่ใช่ "ทุกคนที่มีบัญชี Google" เพราะหน้าเว็บบน GitHub เรียกแบบไม่ล็อกอิน Google; ระบบมีล็อกอินของตัวเอง)
5. คัดลอก **URL เว็บแอป** (ลงท้าย `/exec`) — เปิดในเบราว์เซอร์ ควรเห็น `{"ok":true,"name":"eDMS API",...}`

### ส่วนที่ 2 — GitHub Pages (frontend)
1. แก้ `config.js` ใส่ URL ที่คัดลอกมา
   ```js
   window.EDMS_CONFIG = { apiUrl: "https://script.google.com/macros/s/xxxxxxxx/exec" };
   ```
2. Commit/push `index.html`, `config.js`, `Code.gs`, `README.md` ขึ้น branch `main`
3. ที่ repo: **Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save**
4. รอ 1-2 นาที เปิด `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`
5. ล็อกอินครั้งแรก `admin` / `Admin@1234` แล้ว **เปลี่ยนรหัสผ่านทันที**

## ตั้งค่าหลังติดตั้ง (แอดมิน)
1. **แผนก** → 2. **ประเภทเอกสาร / วัตถุประสงค์** → 3. **ผู้ใช้งาน** (กำหนดแผนก + สิทธิ์อัปโหลด/สืบค้นรายบุคคล) → 4. **ตั้งค่าระบบ**

## อัปเดตระบบภายหลัง
- แก้ `index.html` / `config.js` → push ขึ้น GitHub (Pages อัปเดตเอง)
- แก้ `Code.gs` → วางใน Apps Script แล้ว **Deploy → จัดการการทำให้ใช้งานได้ → แก้ไข (ไอคอนดินสอ) → เวอร์ชันใหม่ → ทำให้ใช้งานได้** (URL เดิมไม่เปลี่ยน; ถ้าสร้างรายการใหม่ URL จะเปลี่ยนและต้องแก้ `config.js`)
- เมื่อโครงสร้างชีตเปลี่ยน ระบบจะเพิ่มคอลัมน์/ชีตให้เองโดยไม่ลบข้อมูลเดิม

## ความปลอดภัย (ควรรู้)
- URL ของ Apps Script เปิดรับคำขอจากทุกที่ การป้องกันอยู่ที่การล็อกอิน (รหัสผ่านเก็บแบบ salt + SHA-256, token หมดอายุ 6 ชม., ผิด 5 ครั้งล็อก 5 นาที) และ **ตรวจสิทธิ์ที่ฝั่งเซิร์ฟเวอร์ทุกคำขอ**
- ตั้งรหัสผ่านแอดมินให้คาดเดายาก และอย่าใส่เอกสารลับสุดยอดในระบบที่เปิดผ่านอินเทอร์เน็ตโดยไม่ผ่านการประเมินความเสี่ยงของหน่วยงาน
- repo เป็น public: ไม่มีข้อมูลหรือรหัสผ่านอยู่ใน repo (มีเพียง URL ของ API ใน `config.js`)
- จำกัดสิทธิ์แก้ไข Google Sheet เฉพาะผู้ดูแล และห้ามแก้หัวคอลัมน์

## ข้อจำกัด
- ไฟล์ละไม่เกิน 20 MB (ปรับได้ถึง 50 MB; ไฟล์ใหญ่จะช้า)
- โควตาของ Apps Script (จำนวนคำขอ/เวลาทำงานต่อวัน) เป็นไปตามบัญชี Google ที่ deploy
- โหมด "เปิดดู" เปิดในแท็บใหม่ ถ้าเบราว์เซอร์บล็อกป๊อปอัป ระบบจะดาวน์โหลดแทน

## ปัญหาที่พบบ่อย
| อาการ | วิธีแก้ |
|---|---|
| "ยังไม่ได้ตั้งค่า apiUrl" | แก้ `config.js` ให้เป็น URL `/exec` ที่ถูกต้อง แล้ว push + รีเฟรชแรงๆ (Ctrl+F5) |
| "เชื่อมต่อเซิร์ฟเวอร์ไม่ได้" | ตรวจว่า deploy เป็น "ทุกคน" และเปิด URL `/exec` ตรงๆ แล้วเห็น JSON |
| แก้ `Code.gs` แล้วไม่เปลี่ยน | ต้อง Deploy เวอร์ชันใหม่ทุกครั้ง |
| Pages ขึ้น 404 | ต้องมี `index.html` (ตัวพิมพ์เล็ก) ที่รากของ branch ที่เลือก และรอ 1-2 นาที |
